DeetsMusic browser extension

What it does

Adds a toolbar button. On a YouTube (or YouTube Music) page, one click looks the song up on Apple Music and a + adds it to your library — through the DeetsMusic app, so no Apple credentials ever live in the browser.

Install (Chrome / Edge / Brave)

Until it's on the Web Store the extension loads "unpacked" from the DeetsMusic install folder. Chrome won't let a page open its extensions screen, so step 1 is a paste.

  1. Open a new tab and go to chrome://extensions Edge: edge://extensions · Brave: brave://extensions
  2. Turn on Developer mode (top right).
  3. Click Load unpacked and pick this folder:
  4. Pin DeetsMusic from the puzzle-piece menu so the button is always visible.
  5. That's it — with DeetsMusic running, click the button on any YouTube video. (The settings page that opens on install has a Test connection button if you want to check.)
